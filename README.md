# قیراط | Qirato Landing

صفحه معرفی و دانلود رسمی قیراط برای **اندروید و ویندوز**، با رابط فارسی RTL و تایپوگرافی Vazirmatn. سایت با HTML، CSS و JavaScript ساده اجرا می‌شود و به مرحله build نیاز ندارد.

## امکانات صفحه

- معرفی دو نسخه با تصاویر واقعی برنامه؛ قاب رسمی ROG Strix G16 G615 و Galaxy S25 Ultra
- مقایسه پکیج‌ها: قیراط اندروید از ۱۴٬۹۰۰٬۰۰۰ به ۹٬۹۰۰٬۰۰۰ تومان (۵ میلیون تومان تخفیف)؛ قیراط کامل از ۳۴٬۹۰۰٬۰۰۰ به ۲۴٬۹۰۰٬۰۰۰ تومان (۱۰ میلیون تومان تخفیف)، با تمام امکانات یکسان در اندروید و ویندوز و همگام‌سازی اطلاعات بین دستگاه‌ها
- اتصال خرید هر پکیج به شماره فروش فعلی سایت
- دانلود آخرین فایل رسمی APK و MSI از انتشارهای GitHub، بدون نمایش شماره نسخه
- کد QR برای دانلود اندروید، ماشین‌حساب نمونه و گالری تصاویر
- حالت روشن/تیره، چیدمان واکنش‌گرا و پشتیبانی از reduced motion
- نوار مظنه با داده‌های **نمونه**؛ این صفحه نرخ زنده دریافت نمی‌کند

## اجرای محلی

از پوشه پروژه اجرا کنید:

```powershell
python -m http.server 8088 --bind 127.0.0.1
```

صفحه در `http://127.0.0.1:8088` در دسترس است.

## بررسی

Node.js برای بررسی JavaScript و اجرای تست‌ها کافی است:

```powershell
node --check js/main.js
node --check js/downloads.js
node --test tests/downloads.test.cjs
```

تست‌ها انتخاب مستقل انتشار اندروید/ویندوز، کنارگذاشتن draft/prerelease، معماری و مسیر فایل، صفحه‌بندی و خطای API را بررسی می‌کنند. تست‌ها هیچ APK یا MSI دانلود نمی‌کنند.

## مسیر دانلود

`js/downloads.js` متادیتای عمومی انتشارهای `urmiaking/goldex-companion` را می‌خواند و جدیدترین فایل نصب منتشرشده هر پلتفرم را به دکمه همان پلتفرم وصل می‌کند. مسیرهای فایل باید متعلق به همان مخزن و وضعیت asset باید `uploaded` باشد. این مسیر به توکن نیاز ندارد.

اگر API در دسترس نباشد یا محدودیت درخواست داشته باشد، اندروید مسیر رسمی `releases/latest/download/app-release.apk` را حفظ می‌کند؛ دکمه ویندوز به صفحه انتشارهای رسمی می‌رود و متن وضعیت مسیر جایگزین را توضیح می‌دهد. QR نیز مسیر ثابت آخرین APK را استفاده می‌کند. انتشار Windows-only نباید GitHub latest اندروید را تغییر دهد؛ این همان سیاست انتشار مخزن برنامه است.

## طراحی و قیمت‌ها

بخش اول صفحه به معرفی قیراط و آشنایی با امکانات اختصاص دارد؛ قیمت‌ها پس از معرفی نسخه‌ها، امکانات و تصاویر، در بخش پکیج‌ها نمایش داده می‌شوند.

رنگ‌ها از توکن‌های موجود Persian Sovereign Aurum در `css/main.css` گرفته می‌شوند. `css/platforms.css` چیدمان معرفی دو دستگاه، پکیج‌ها و دانلود را تعریف می‌کند. تصاویر واقعی ویندوز در حالت روشن/تیره از اجرای Compose Desktop ثبت شده‌اند و همراه تغییر تم صفحه عوض می‌شوند؛ منابع قاب‌ها و اسکرین‌شات‌ها در [مستند تصاویر](docs/device-assets.md) آمده است. متن و قیمت‌های نمایش‌داده‌شده در `index.html` هستند؛ قیمت‌های JSON-LD به ریال ثبت شده‌اند و باید همراه قیمت‌های تومانی صفحه تغییر کنند.

## استقرار

Dockerfile و تنظیمات Nginx موجود، فایل‌های ایستا را سرو می‌کنند. compose از image موجود در رجیستری پروژه استفاده می‌کند؛ قبل از استقرار باید image جدید ساخته و منتشر شود یا روش استقرار مستقیم فایل‌ها با تنظیمات سرور هماهنگ شود. نسخه تأییدشده در [qirato.ir](https://qirato.ir/) منتشر شده است؛ هویت ایمیج، بررسی‌ها و راه بازگشت در [گزارش انتشار](docs/deployments/2026-10-13-android-windows-landing.md) ثبت شده‌اند.
