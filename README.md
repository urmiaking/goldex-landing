# Qirato Landing Page (لندینگ پیج اختصاصی اپلیکیشن قیراط) 🪙

وب‌سایت معرفی، محاسبه‌گر زنده و مرکز دانلود رسمی برای اپلیکیشن موبایل **قیراط (Qirato | GoldEx Companion)**.

## ویژگی‌ها
- **طراحی دیزاین سیستم Persian Sovereign Aurum:** پالت لوکس زرین (طلای شامپاینی `#D4AF37`، طلای ناب `#B8860B`، و ذغالی ابسیدین `#080B11`)
- **ماشین‌حساب زنده زرگری:** با فرمول دقیق اتحادیه طلا و جواهر (معافیت اصل طلا، سود ۷٪، مالیات ارزش‌افزوده ۹٪ طبق ماده ۲۶ و تبدیل به حروف)
- **تابلوی مظنه لحظه‌ای:** استعلام و نمایش مظنه طلا، سکه، ارز و حباب سکه
- **گالری اسکرین‌شات‌ها (Google Stitch Integration):** تصاویر باکیفیت بخش‌های مختلف اپلیکیشن همراه با لایت‌باکس
- **مرکز دانلود جامع:** دانلود مستقیم فایل نصب اندروید (APK)، بارکد QR اسکن موبایل و لینک به مخزن رسمی گیت‌هاب
- **عملکرد بهینه و انیمیشن‌های نرم:** کاملاً سخت‌افزاری بر پایه استاندارد‌های Emil Kowalski بدون افت فریم

## پیش‌نمایش محلی
برای اجرای پیش‌نمایش در مرورگر:
```bash
python -m http.server 8080
```
سپس آدرس `http://localhost:8080` را در مرورگر باز کنید.
